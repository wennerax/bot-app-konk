# Telegram Giveaway Bot

Node.js-бот на grammY и Fastify с Mini App по адресу `https://bred.bothost.tech`.

## Запуск

1. Установите Node.js 20+.
2. Выполните `npm.cmd install`.
3. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN`.
4. Создайте Mini App в BotFather, укажите его короткое имя в `MINI_APP_NAME` и URL `https://bred.bothost.tech`.
5. Добавьте бота администратором канала. Для проверки подписок ему нужен доступ к участникам канала.
6. В панели хоста укажите главный файл `server.js` и запустите `npm.cmd start`.

На хосте задайте `PUBLIC_URL=https://bot-1789719870-1665-wennera.bothost.tech`; если переменная не задана, приложение использует этот адрес по умолчанию. Короткий адрес `https://bred` не подходит, потому что Telegram не сможет найти такой DNS-host. Для локального запуска можно задать `PUBLIC_URL=http://localhost:3000`, тогда бот использует long polling.

Проверить, куда Telegram отправляет команды, можно по адресу `/api/telegram-status`. `webhookUrl` должен совпадать с реальным адресом приложения и заканчиваться на `/telegram/webhook`.

`MANAGED_CHANNELS` принимает JSON, например:

```json
[{"id":"-1001234567890","title":"Мой канал","url":"https://t.me/example"}]
```

Бот автоматически запоминает канал, когда Telegram присылает событие добавления бота (`my_chat_member`) или новый пост (`channel_post`). Это работает и для приватных каналов, username для них не нужен. Для уже добавленного приватного канала после обновления бота сохраните права администратора или опубликуйте новый пост, затем отправьте `/menu`. `MANAGED_CHANNELS` остаётся необязательным резервным способом.

## Команды

- `/setconditions ID_канала | @партнер1, @партнер2` включает проверку подписки на сам канал и партнёров.
- `/setappcolor ID_канала | #ff5a36` меняет цвет кнопки участия внутри Mini App.
- В меню канала пункт `⏰ Дата итогов` задаёт дату и время автоматического подведения итогов для новых конкурсов.

Цвет обычной inline-кнопки под постом Telegram невозможно менять через Bot API. Настройка цвета применяется только к кнопке внутри Mini App; Telegram сам определяет цвет кнопки в канале.

Планировщик проверяет сроки каждые 15 секунд. После даты конкурс закрывается, победители публикуются в канале, а каждому победителю отправляется личное сообщение. Telegram разрешает боту писать пользователю только если пользователь ранее открыл чат с ботом и нажал Start.

При создании через меню бот после названия, количества победителей и описания отдельно попросит дату именно этого конкурса. Формат: `2026-10-01 20:00`. Если отправить `нет`, конкурс останется без автоматического завершения.

## Проверки

`npm.cmd test` запускает unit-тесты доменной логики. Данные production хранятся в локальном файле `data/bot-data.json`: `channels` хранит каналы и настройки, `giveaways` конкурсы и участников. Путь можно изменить переменной `DATA_FILE`. Для сохранения данных между redeploy убедитесь, что хост сохраняет каталог проекта или подключите persistent volume.
