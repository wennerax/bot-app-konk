# Telegram Giveaway Bot

Node.js-бот на grammY и Fastify с Mini App по адресу `https://bred.bothost.tech`.

## Запуск

1. Установите Node.js 20+.
2. Выполните `npm.cmd install`.
3. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN`.
4. Создайте Mini App в BotFather, укажите его короткое имя в `MINI_APP_NAME` и URL `https://bred.bothost.tech`.
5. Добавьте бота администратором канала. Для проверки подписок ему нужен доступ к участникам канала.
6. В панели хоста укажите главный файл `server.js` и запустите `npm.cmd start`.

На хосте задайте `PUBLIC_URL=https://bred.bothost.tech`; если переменная не задана, приложение использует этот адрес по умолчанию. Короткий адрес `https://bred` не подходит, потому что Telegram не сможет найти такой DNS-host. Для локального запуска можно задать `PUBLIC_URL=http://localhost:3000`, тогда бот использует long polling.

Проверить, куда Telegram отправляет команды, можно по адресу `/api/telegram-status`. `webhookUrl` должен совпадать с реальным адресом приложения и заканчиваться на `/telegram/webhook`.

`MANAGED_CHANNELS` принимает JSON, например:

```json
[{"id":"-1001234567890","title":"Мой канал","url":"https://t.me/example"}]
```

## Команды

- `/menu` ищет каналы, где пользователь администратор и бот может проверять участников.
- `/newgiveaway Название | 3 | -1001234567890` создаёт конкурс и публикует кнопку в канале.
- Кнопка ведёт в `/start g_<id>`, где бот проверяет обязательные подписки и регистрирует участника.
- Если конкурс создаётся ответом на фото, видео или документ с командой `/newgiveaway`, медиа будет опубликовано вместе с конкурсом.
- Telegram Premium custom emoji сохраняются из entities сообщения модератора и выводятся в публикации конкурса. Отдельный ID в `.env` для этого не нужен.

## Проверки

`npm.cmd test` запускает unit-тесты доменной логики. В текущем MVP данные хранятся в памяти; перед production подключите PostgreSQL через реализацию интерфейса `MemoryStore` и добавьте проверку Telegram WebApp init data для административных API.
